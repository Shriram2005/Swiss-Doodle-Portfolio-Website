# 🇨🇭 Swiss-Doodle Portfolio Website ✨

> A multi-page personal portfolio blending the mathematical structure and high contrast of the **Swiss International Typographic Style** with the playful warmth of **cute hand-drawn notebook doodles**.

Crafted for **Shriram Mange** — Android Developer & Full-Stack Web Engineer.

---

## 🌟 Highlights

- **📄 Multi-Page Experience:** Clean, dedicated pages for [Home](index.html), [About & Journey](about.html), [Projects](projects.html), [Experience](experience.html), and [Contact Postcard](contact.html).
- **🎨 3 Switchable Themes:**
  - 🎨 **Warm Paper Notebook** (Default cream paper & pastel highlights)
  - 🇨🇭 **Swiss Poster** (Crisp high-contrast white, black & Swiss Red)
  - 🌙 **Blueprint Midnight** (Dark slate with neon cyan & mint doodles)
- **🔍 Architecture Inspector Modal:** Deep technical breakdown of 14+ projects covering architecture, security, and cloud infrastructure.
- **🎵 Built-in Web Audio SFX:** Tactile pop and click sounds synthesized in real-time via the browser's native `AudioContext` (zero audio files needed, fully toggleable).
- **⭐️ Interactive Stamp Playground:** Tap cute stickers (⭐️, 🤖, ☕, ✨, 🚀) and stamp them anywhere on the page.
- **⚡ Zero Dependencies:** Built purely with semantic HTML5, Vanilla CSS3 (custom design system), and modern ES6+ JavaScript. Fast, accessible, and lightweight.

## 🚀 Running Locally

No build tools or package managers required. Simply open `index.html` in your browser, or spin up a local server:

```bash
# Python
python -m http.server 8080

# Or Node.js
npx serve .
```

Open `http://localhost:8080` in your browser.
